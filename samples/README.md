# Desktop samples

[Foundation](foundation/application.norm) combines the core widgets, theme and configuration providers with the JavaFX backend. Its [native interaction test](foundation/tests/test/flow/case.norm) verifies counter and theme actions through a real window.

[hello.norm](hello.norm) is the minimal desktop counter. Run `norm run samples/hello.norm`.
